
# Convite de aniversário

Landing page responsiva desenvolvida com HTML, CSS e JavaScript.

## Estrutura

- `index.html`: conteúdo e formulários
- `css/style.css`: estilos e layout responsivo
- `js/script.js`: interações e envio dos formulários

## Configuração

1. Configure o formulário externo no Formspree.
2. Adicione o endpoint público em `js/script.js`.
3. Atualize data, horário, endereço e textos em `index.html`.
4. Teste os formulários antes de compartilhar o convite.

## Publicação

O site pode ser publicado pelo GitHub Pages.

## Privacidade

- Não salvar respostas no repositório.
- Não incluir senhas ou tokens privados no código.
- Restringir o acesso às respostas aos organizadores autorizados.
- Apagar as respostas quando não forem mais necessárias.
- Não publicar mensagens sem autorização.
